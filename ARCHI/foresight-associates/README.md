## 3. Technology Stack (Strict Frontend Only)

This website is engineered strictly using frontend standards:

* **HTML5:** Semantic architecture (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* **CSS3:** Custom properties (CSS variables), CSS Grid, Flexbox, media queries, keyframe animations, `@media (prefers-reduced-motion: reduce)`.
* **Vanilla JavaScript (ES6+):** Smooth scrolling, interactive mobile drawer navigation, category filtering, interactive Quick-View modal, keyboard navigation, and form validation.
* **Zero Dependencies:**
  * No React, Next.js, Angular, Vue, or TypeScript.
  * No Tailwind, Bootstrap, or CSS frameworks.
  * No Node.js, PHP, Python, or backend server requirements.
  * No database or CMS.

## 7. How to Run Locally

Because this website is completely static, it can be run instantly in any modern web browser without any build step, installation, or server configuration:

### Method A: Direct Browser Opening
1. Double-click `foresight-associates/index.html` (or right-click &rarr; *Open with* &rarr; Google Chrome, Microsoft Edge, Firefox, or Safari).
2. The entire website is fully operational.

### Method B: Using Any Local Static Server (Optional)
If you prefer running through a local HTTP server:
* Using Python:
  ```bash
  cd foresight-associates
  python -m http.server 8000
  ```
  Then open `http://localhost:8000` in your browser.
* Or using any standard static file previewer (VS Code Live Server, etc.).
